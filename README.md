# Oxford · Психиатрия

Личный учебный маршрут по Shorter Oxford Textbook of Psychiatry, 8th edition.

26 глав, 438 занятий, чтение, озвучивание через Web Speech API, конспекты, поиск и экспорт прогресса. Текст книги на английском, интерфейс на русском.

## Запуск

Готовая страница находится в `dist/index.html`. Для локального просмотра:

```sh
python -m http.server 8000 --directory dist
```

Откройте http://localhost:8000.

## Изменение

Интерфейс и JavaScript находятся в `template.html`. После изменений пересоберите страницу:

```sh
pip install -r requirements.txt
python build.py
```

Скрипт извлекает текст из `dist/book.pdf`, обновляет `data.json` и встраивает его в HTML. Серверная часть не требуется.

## Vercel

В проекте есть `vercel.json` с каталогом публикации `dist`. Готовые файлы уже включены, отдельная сборка не требуется. Доступ к размещённому сайту настраивается отдельно от приватности GitHub: приватный репозиторий сам по себе не закрывает сайт.

## Данные и ограничения

Прогресс и конспекты хранятся в localStorage этого браузера. Используйте экспорт для резервного копирования и переноса. Доступность голосов зависит от браузера и устройства. Таблицы и иллюстрации проверяйте в исходном PDF.

Репозиторий содержит предоставленный пользователем учебник и его текст. Предназначен для личного использования; храните репозиторий приватным. Права на книгу принадлежат правообладателям; разрешение на распространение книги не предоставляется.
